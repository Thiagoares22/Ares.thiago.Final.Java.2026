# Sistema de Vehículos

## Descripción

Este proyecto consiste en un sistema para gestionar vehículos.
Permite registrar, modificar, eliminar, ordenar y filtrar
vehículos.

El sistema trabaja con diferentes tipos de vehículos:

- Auto
- Moto
- Camión
